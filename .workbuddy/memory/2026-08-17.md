## Dashboard TOTP 双因素认证（用户要求）

- `AppSetting` 表（key-value，值 AES-GCM 加密）存 `admin_totp_secret`（base32）。
- `src/lib/totp.ts`：RFC 6238 手写实现（HMAC-SHA1/6位/30s/±1窗口），含 base32 编解码；**已用 RFC 6238 官方测试向量验证**（T=59 → 287082 ✅）。
- 两步登录：密码通过 → 下发 5 分钟 `licentra_pending_2fa` JWT cookie（purpose: `totp` / `totp-setup`）→ 有密钥则要求 6 位码（`verifyTotpAction` 校验后发完整会话）；无密钥则强制 `/setup-2fa`（QR + 手动密钥 + 确认码，密钥内嵌在签名 cookie 里、不信任客户端输入）。
- 页面：login-form 两步切换（useActionState）、`/setup-2fa` + setup-totp-form（qrcode 包生成 QR dataURL）；proxy.ts 加 `/setup-2fa` 守卫；logout 清 pending。
- `scripts/bootstrap-2fa.ts`（package.json: `bootstrap:2fa`）：生成/保留/`--rotate` 密钥 + 输出 otpauth URI / secret / QR PNG。已运行：密钥已入库，二维码在项目根 `totp-setup-qr.png`，**用户扫码后需删除该 PNG（含密钥）**。
- 坑：tsx 脚本不会自动加载 .env.local，而 Prisma 单例在**模块加载时**读 DATABASE_URL → 新建 `scripts/load-env.ts` side-effect 模块，脚本必须**首个 import** 它。
- 依赖：qrcode + @types/qrcode。验证：RFC 向量 ✅、tsc ✅、db push ✅（未跑 next build）。
- 文档：README 安全模型、PROJECT.md §2.6 与数据模型表已更新。
- 用户扫码完成，已删除 `totp-setup-qr.png`；README 新增 "Two-factor authentication (dashboard)" 小节，写明恢复方式：删 `AppSetting.admin_totp_secret` 行即重新走强制设置流程（getTotpSecret() 返回 null → loginAction 走 totp-setup）。
